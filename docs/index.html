Pourquoi Nova

Conçue pour vivre sur ta machine — pas dans un nuage.

🗣️

Voix naturelle

Parle, elle répond. Les voix françaises de macOS, et la lecture démarre phrase par phrase pendant que le modèle écrit encore.

🧠

Mémoire réelle

Conversations, profil, programme de sport : tout est sauvegardé localement et réinjecté dans son contexte — même après redémarrage.

🛡️

Sandbox sécurisée

Liste blanche d'actions, arguments validés, exécution sans shell. Chaque action sur le Mac affiche une carte Autoriser / Ignorer.

⚡

Zéro dépendance

Le serveur est du Node.js pur : pas de framework, pas de npm install. 68 tests couvrent la sécurité et le moteur sport.

🌙

Mot d'activation

Dis « Nova » comme tu dirais « Siri » : elle s'éveille, écoute ta question, répond, puis se rendort toute seule.

🏋️

Coach sportif

Elle lit ton programme Pulse : séance du jour, technique d'un mouvement, progression — « Nova, séance terminée » valide d'un mot.

🖥️

Contrôle du Mac

Ouvrir une app, régler le volume, notifier, capturer l'écran, lire batterie, météo, disque — données réelles, jamais inventées.

📱

Vraie app macOS

Compilée pour Apple Silicon : fenêtre vibrance, icône dans le Dock, permissions micro intégrées. DMG arm64 prêt à installer.

Installer

Trois commandes et une clé gratuite.

# 1. le projet
git clone https://github.com/DmzGamingYT/nova.git && cd nova

# 2. ta clé Groq (gratuite — console.groq.com/keys)
cp .env.example .env    # puis GROQ_API_KEY=gsk_…

# 3. lance
./start.command         # → http://localhost:8787

Ou l'app native : cd desktop && npm install && npm run dist → Nova.app (DMG arm64).
