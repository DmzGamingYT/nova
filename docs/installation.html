Installer Nova

Trois commandes et une clé gratuite — ou l'app native.

# 1. le projet
git clone https://github.com/DmzGamingYT/nova.git && cd nova

# 2. ta clé Groq (gratuite — console.groq.com/keys)
cp .env.example .env    # puis GROQ_API_KEY=gsk_…

# 3. lance
./start.command         # → http://localhost:8787
1

Récupère le projet

Un simple git clone. Aucune dépendance npm côté serveur : Node.js ≥ 20 suffit.

2

Ta clé Groq

Crée une clé gratuite sur console.groq.com/keys. Elle reste sur ta machine. Sans clé, Nova tourne en mode démo.

3

Double-clique

start.command lance le serveur et ouvre ton navigateur. Maintiens la barre espace et parle.

Ou l'app barre de menus

Icône dans la barre de menus, panneau flottant ⌘⇧Espace, permissions micro intégrées — build Apple Silicon par la CI.

# compiler toi-même
cd desktop && npm install && npm run dist
# → release/Nova-1.0.0-arm64.dmg

# ou télécharger le DMG construit par la CI
open https://github.com/DmzGamingYT/nova/releases

Le DMG n'est pas signé (build personnel) : au premier lancement, clic droit → Ouvrir.
