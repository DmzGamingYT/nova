— ou compiler toi-même — 
# 1. le projet
git clone https://github.com/DmzGamingYT/nova.git && cd nova

# 2. ta clé Groq (gratuite — console.groq.com/keys)
cp .env.example .env    # puis GROQ_API_KEY=gsk_…

# 3. lance
./start.command         # → http://localhost:8787
1

Récupère le projet

Un simple git clone. Aucune dépendance npm côté serveur : Node.js ≥ 20 suffit.

2

Ta clé Groq

Crée une clé gratuite sur console.groq.com/keys. Elle reste sur ta machine. Sans clé, Nova tourne en mode démo.

3

Double-clique

start.command lance le serveur et ouvre ton navigateur. Maintiens la barre espace et parle.

L'app en détail

Icône dans la barre de menus, panneau flottant ⌘⇧Espace, raccourci global, permissions micro intégrées — compilée pour Apple Silicon par la CI à chaque release.

# compiler toi-même (build ad-hoc local)
cd desktop && npm install && npm run dist
# → release/Nova-<version>-arm64.dmg

# compiler + signer + notariser (secrets Apple requis)
cd desktop && npx electron-builder --mac --arm64 --publish always

Quand une version signée sera publiée, l'app se mettra à jour toute seule (electron-updater, notifications incluses). En attendant, retélécharge simplement chaque nouvelle release.
