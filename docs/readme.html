✨ Pourquoi Nova

Six idées simples, tenues d'un bout à l'autre du projet.

Voix naturelle

Tu parles, elle répond : voix françaises de macOS, lecture phrase par phrase pendant que le modèle écrit.

Mémoire réelle

Conversations, profil, programme de sport — elle s'en souvient, même après un redémarrage.

Sandbox sécurisée

Liste blanche d'actions, exécution sans shell, carte de confirmation avant tout geste sur le Mac.

Zéro dépendance

Le serveur est du Node.js pur : pas de npm install, pas de framework — et 95 tests.

Mot d'activation

Dis « Nova » comme tu dirais « Siri » : elle s'éveille, écoute, répond, se rendort.

Coach sportif

Elle lit ton programme Pulse : séance du jour, technique, progression, validation vocale.

🚀 Démarrage rapide

Trois commandes, aucune installation — et sans clé API, Nova tourne déjà en mode démo.

1

Récupère le projet

git clone puis cd nova — quelques secondes, zéro dépendance.

2

Ta clé Groq (gratuite)

cp .env.example .env puis colle ta clé de console.groq.com/keys.

3

Lance

./start.command — double-clic possible. L'interface s'ouvre sur 127.0.0.1:8787.

git clone https://github.com/DmzGamingYT/nova.git && cd nova
# 2. ta clé Groq (gratuite — console.groq.com/keys)
cp .env.example .env      # puis GROQ_API_KEY=gsk_…
./start.command           # → http://127.0.0.1:8787

Sans clé API, Nova tourne en mode démo : interface, voix et streaming fonctionnent, les réponses sont pré-écrites. Avec une clé, elle devient pleinement intelligente — tu peux aussi la coller dans les Réglages (⚙️ ou ⌘,), elle reste sur ta machine. → Guide d'installation complet

📱 App native — macOS & Windows

Une vraie app de barre de menus : l'orbe vit au-dessus de tout, à un raccourci de n'importe où.

Panneau façon Spotlight

Un clic sur l'icône de barre de menus — ou ⌘⇧Espace (Ctrl⇧Espace sous Windows) — ouvre un panneau flottant au-dessus de tout, replié dès que tu cliques ailleurs ou tapes Échap.

Installation directe

Chaque tag v* publie un DMG macOS et un installeur Windows NSIS sur les releases GitHub, avec SHA256SUMS.txt et changelog automatiques.

Serveur embarqué

L'app packagée contient son propre serveur Nova : port libre au lancement, données dans le dossier utilisateur — rien d'autre à installer.

DMG non signé (build personnel) : au premier lancement, clic droit → Ouvrir. Chaque release publie SHA256SUMS.txt pour vérifier ton téléchargement — la marche à suivre détaillée est sur la page Dépannage.

🏗️ Architecture

Un dépôt plat, lisible d'un coup d'œil — chaque dossier a un rôle unique.

server.js

Serveur Node sans dépendance : statiques, proxy SSE Groq (filtre <think>, bascule de modèle, retry OTPM), Whisper STT, mémoire, sandbox.

lib/

skills.js — compétences de lecture (heure, météo, batterie…)
training.js — moteur sport : plan Pulse, phases, progression.

public/

Interface : conversation, micro, voix, réglages, VAD, barge-in, minuteurs, mot d'activation, orbe réactive, mini-markdown.

desktop/

Application Electron : barre de menus, panneau flottant, raccourci global, builds DMG arm64 / NSIS Windows, serveur embarqué.

test/

95 tests sur un vrai serveur avec dossier temporaire : sandbox, traversée de répertoire, parité Windows, moteur sport.

data/

Mémoire, profil et progression sport (gitignored) — tout vit chez toi, rien ne sort de la machine.

Confidentialité : la clé passe uniquement entre ton navigateur → serveur local → api.groq.com. Rien d'autre, aucun stockage distant. Les actions Mac exigent ta confirmation, une par une.
